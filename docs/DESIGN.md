# おもちゃいろモンスター図鑑 v2 設計 — 「なんどもやりたくなる」ための施策

対象: 幼児〜小学校低学年が一人で遊べること。サーバー無し・保存は localStorage のみ。

## いまのゲームの弱点（2026-11-07 調査。Claude・AGY・Codex の読解とプレイで確認）

| 種類 | 内容 |
|---|---|
| 進行不能 | 裏ステージ（難易度 6）が開くと `Array(5 - 6)` で画面が落ちる / ボス戦で「つぎのバトルへ」を押すと固まる（`key` が同じ） |
| 効いていない | とくぎは演出だけで計算に反映されない（`setTimeout` 内で古い状態を読む）/ なつき度がどこにも効かない |
| 数値の破綻 | おやつが無料・無制限で連打だけで能力 999 / 合成が素材を消費せず無限に★5 / 毎戦レベルアップ / 表示 XP と実際がずれる / ひかり⇔やみが互いに弱点 |
| 選択の薄さ | バトルは 1 匹選んだら全自動（約 12 秒見るだけ）/ 3 匹選ぶ意味がない / クイズは同じ答え→同じ子で、重複は無言で捨てる |
| 見た目 | 画像が外部アバター（人の顔・図形・アイコン）で「モンスター」に見えない子が多く、成長しても姿が変わらない |

## 施策（入れる順）

### 1. セーブ基盤と致命的バグの修正
- 新しい進行データを別キー `mystery-pet-progress-v1` に保存（既存の `mystery-pet-collection` は壊さない。旧 `mystery-pet-has-egg` は移行）
- 各モンスターに無い項目は読み込み時に既定値を補う

### 2. 自作 SVG モンスター + しゅぞく図鑑 + いろちがい
- 外部画像をやめ、`imagePrompt` から決定論的に描く SVG モンスター（からだ 6 形 × 属性 8 色 × 目・口・つの・しっぽ等）。オフラインでも出る
- **しゅぞく = からだの形 × 属性 = 48 種**。図鑑に No.001〜048 の枠を並べ、未発見はシルエット「？」。「あと 3 しゅで もりのなかまが そろう！」→ **収集の穴を埋めたい欲求**
- **いろちがい**（1/24）: 色が反転したキラキラ個体。図鑑に別マーク → **レア探し**
- 既存のセーブは `imagePrompt` から同じ姿に描けるので移行不要。いろパパ・いろママは写真のまま

### 3. じゃんけん式ターン制バトル + ステージの★
- わざは 3 つ: ✊ パワー / ✌️ スピード / ✋ かしこさ。✊>✌️>✋>✊ のじゃんけん。勝つと 1.5 倍、負けると 0.5 倍
- **てきは次に出すわざを予告**する（奥のステージほど「？」で隠れる）→ 読み合いの手応え。子供でも「グーにはパー」で分かる
- HP 制。たおれたら控えと交代 → **3 匹チームに意味が出る**
- とくぎゲージ: じゃんけんに勝つと多く溜まる。満タンで必殺（2.5 倍・必中）
- **なつき度 80 以上**: 1 バトルに 1 回、たおれる攻撃を HP1 でふんばる → お世話がバトルに効く
- ステージは 3 戦（ざこ 2 → ステージボス）。HP は持ち越し。クリアで **★1〜3**（たおれた数で決まる）。前のステージをクリアすると次が開く
- クリア後「どの子を つれてかえる？」を倒した敵から 1 匹えらぶ（自動で仲間入りはしない）

### 4. しんか + 育成の数値
- Lv8 で 2 だんかい、Lv20 で 3 だんかい。姿が大きくなり、つの・はね・かんむりが増え、名前が変わる。**しんか演出**つき → **育てる目標**
- 必要 XP はレベルとともに増える（毎戦レベルアップしない）。レベルアップの能力上昇は +3
- 敵の強さはステージごとの帯で決める（はじまりの町が最初の子より強い、をなくす）

### 5. まいにち（スタンプ・ミッション・おやつ）
- **スタンプカード**: 1 日 1 回ひらくと 1 こ。7 こでタマゴ（きん）→ **毎日ひらく理由**
- **きょうのミッション 3 つ**（日付で決まる）: 例「✊で 3 かい かつ」「ほのおタイプで ステージクリア」「10 かい なでなで」→ おやつ・タマゴ
- **おやつは持ち物制**: バトル・ミッション・スタンプでもらう。あげると能力 +2。無料連打をなくす
- なでなでは無料のまま（1 日になつき度が上がる回数に上限）

### 6. タマゴ・クイズ・合成の磨き直し
- タマゴは ふつう / きん / にじ の 3 ランク。ステージクリアで「あたためポイント」がたまり、かえる。ランクが高いほどレア・いろちがいが出やすい
- クイズの答えで **属性とからだの形が決まり**、個体（名前・能力・いろちがい）は毎回ちがう → 同じ答えでも毎回新しい子
- 合成: 親は残すが、両方 Lv5 以上が条件。能力は親の高いほう + 10%。名前の「超超超…」を直す

## 保存データ
- `mystery-pet-collection`（既存・配列）: 項目追加のみ。`shiny?` `isFused?` など
- `mystery-pet-progress-v1`（新規）: おやつ・ステージ★・スタンプ・ミッション・タマゴ・なでなで回数・統計
